# 일반화된 생성이미지 탐지를 위한 개선 방향 메모

> 대상: tre-diffusion-image-detection (TRE/TAF/TOD) 후속 연구.
> 주의: 원논문의 Ours 수치(66.0/68.0/68.4%)는 실험 미완료 상태의 값이라
> 신뢰 불가(저자 확인) — 아래 논의는 그 수치가 아니라 **구현 분석과 재현
> 실측**에 근거한다. 궁극 목표는 **보지 못한 생성기에도 일반화되는 탐지**.

## 1. 현재 방식의 병목 진단

### 1-1. TRE 특징이 수학적으로 ~0에 수렴함 (재현 중 실측 확인 ★핵심★)
현재 TRE는 edit-friendly DDPM 인버전(eta=1.0)으로 매 스텝의 노이즈
`z_t = (x_{t-1} - mu_t) / sigma_t`를 기록한 뒤, 재구성 때 **그 z_t를 그대로
재주입**한다. edit-friendly 인버전의 정의상 이 재구성은 어떤 prefix에서
시작하든 **원본 latent를 정확히 복원**한다. 따라서 prefix 간 재구성 차이인
TRE는 이론상 정확히 0이고, 실측(서버 재현)에서도 std ≈ 2.7e-4 수준의
**부동소수점/커널 비결정성 잔차**만 남는 것을 확인했다. 원본 노트북
(LoadDataset.ipynb cell 6)도 동일 구현이라, 논문의 66% 성능은 사실상
"GPU 수치 잔차의 이미지 의존적 패턴"을 학습한 결과로 해석된다. 이것이
논문 성능 저조의 근본 원인일 가능성이 매우 높다.
- 개선 1: 재구성 시 **z_t를 재주입하지 않고 새 난수 사용**(zs=None, eta=1)
  → prefix별 재구성이 실제로 달라져서 "모델이 이 이미지를 얼마나 안정적으로
  설명하는가"라는 의미 있는 TRE가 된다.
- 개선 2: **eta=0 (결정론적 DDIM) 인버전 + 재구성 오차** — DIRE/LaRE 계열이
  쓰는 방식. 난수 없이 순수 재구성 능력만 측정.
- 두 방식 모두 기존 파이프라인 코드로 etas/zs 인자만 바꾸면 실험 가능.

### 1-2. O(T²) prefix 재구성 정의
현재 TRE의 k번째 프레임 = "앞쪽 k스텝만으로 복원한 결과"와 "k+1스텝 복원
결과"의 차이. 계산이 스텝²에 비례해 폭발하고(이미지당 UNet 250회),
프레임 간 정보 중복이 크다.
- 개선 A(값싼 대체): **한 번의 역과정 궤적에서 스텝별 latent 차이**를
  기록 (UNet 40회, O(T)). 시간 신호는 유지되면서 5~6배 빨라짐.
- 개선 B(정보 보존): sparse timestep 집합 {t₁..t_K}에서의
  **x0-예측 오차 맵** `E_t = x0 - x0_pred(x_t, t)` 프로파일. K=5면 UNet 5회.
  "타임스텝에 따른 복원오차 프로파일"은 생성기별 특성이 뚜렷하다는
  보고가 많음 (LaRE², SeDID 계열).

### 1-3. 분류기가 신호 대비 과대
(20,4,32,32) 입력에 픽셀별 T-시퀀스 어텐션은 파라미터 대비 정보가 희박.
NPR(92.6%)이 이긴 이유는 **고주파 로컬 아티팩트**가 생성기 불문 공통이기
때문. 어텐션이 이를 평균화해버린다는 자체 분석(논문 4.3)과 일치.

## 2. Novelty가 될 만한 방향

### 2-1. 이중 브랜치: 시간 궤적 x 고주파 잔차 (추천 ★)
- 브랜치 1: 개선된 TRE(결정론적, O(T)) → 가벼운 temporal encoder
- 브랜치 2: 입력 이미지의 **고주파 잔차** (NPR식 이웃픽셀 관계 또는
  SRM/DnCNN 잔차) → 소형 CNN
- 융합: late fusion 또는 cross-attention.
- 논리: 시간 궤적은 "diffusion 계열" 지문, 고주파 잔차는 "업샘플러/디코더"
  지문 → 상호보완이라 **미지 생성기 일반화**에 유리.
- 기존 연구와의 차별점: NPR(공간만), DIRE/LaRE(단일 재구성 오차만),
  STRE(시공간이지만 확률적 TRE)의 조합 지점이 비어 있음.

### 2-2. 타임스텝-프로파일 시그니처 (컴팩트 novelty)
이미지당 K개 timestep에서 x0-예측 오차의 **통계량**(채널별 평균/분산/
고주파 에너지)만 뽑아 K x d 시그니처로 만들고, 얕은 모델(GBM/MLP)로 분류.
- 장점: 이미지당 UNet K회(K=5)라 GenImage 전체 규모도 몇 시간 내 처리.
  해석 가능("어느 timestep에서 갈리는가").
- 실험 프레임: 시그니처의 생성기별 클러스터링 시각화 자체가 논문 그림이 됨.

### 2-3. 파운데이션 특징과의 결합 (강한 베이스라인 겸용)
CLIP/DINOv2 frozen feature + linear probe는 미지 생성기 일반화에서 매우
강함(UniversalFakeDetect, Ojha+ 2023). TRE 시그니처를 CLIP 특징에
**concat만 해도** 일반화 성능이 오르는지가 저비용 고정보 실험.
- "재구성 기반 신호가 semantic 특징에 orthogonal한 정보를 주는가"라는
  질문 자체가 리서치 포인트.

### 2-4. 강건성 프로토콜 (일반화 주장의 필수 조건)
JPEG(Q95/Q75), resize 0.5x, blur 하에서의 성능 표를 반드시 포함할 것.
고주파 기반 방법은 JPEG에 취약 → 시간 궤적 브랜치가 이를 보완하는지가
2-1의 핵심 검증. 학습 시 augmentation(JPEG/blur 랜덤 적용)만으로도
cross-generator 성능이 크게 오른다는 것이 CNNDetection 이래 정설.

### 2-5. 평가 설계 개선
- Accuracy 단독은 임계값에 민감 → **AP(Average Precision) 병기** (코드에
  이미 ap()가 있음).
- leave-one-generator-out: sdv1.4 학습 → 나머지 7개 평가 (현재와 동일)에
  더해, **midjourney 학습 → 나머지 평가** 같은 역방향도 1개 추가하면
  일반화 주장이 훨씬 단단해짐.

## 3. 우선순위 제안 (재현 실험 이후)

> 실험 경과 (2026-08): 1-1의 두 개선안을 모두 전체 규모로 실행했다.
> **B(새 난수)는 실패** — 8개 생성기 평균 50.1%, 학습 acc 96%로 난수 암기.
> **C(eta=0)는 절반 성공** — SD 계열(sdv4/sdv5/wukong) 78.8%·AP 0.86으로
> 처음 실질적 탐지기가 됐지만, 비SD 계열은 49.5%(biggan은 39.8%로 역전).
> 즉 "단일 인버터의 재구성 오차"는 **인버터와 같은 계열만** 잡는다.
> 상세: `docs/finding-tre-collapse.md`.
>
> 따라서 아래 우선순위를 갱신한다: 1번은 완료(성패 확인), 남은 관건은
> **계열 의존성을 어떻게 깨는가**이며 2-1·2-3·2-4가 그 후보다.

1. ~~eta=0 결정론적 TRE~~ — **완료**. 신호는 확보했으나 생성기 계열에
   특화됨(위 경과 참조). 이 조건의 특징·체크포인트는 재사용 가능하므로,
   아래 방향들의 "재구성 브랜치" 자리에 그대로 쓸 수 있다.

1-bis. **계열 의존성 완화** — 세 갈래를 모두 실행했고 결과는 아래와 같다.
   - ~~학습 데이터의 생성기 다양화 + leave-one-generator-out~~ — **완료, 음성**.
     홀드아웃 평균 51.7%, 학습된 생성기에서도 52~58%. 계열 편향은 학습 구성이
     아니라 특징의 성질임이 확정됐다. 이 경로는 닫혔다.
   - ~~여러 인버터 앙상블~~ — **완료했으나 질문에 답하지 못함**. SD2.1을
     쓰려 했으나 `stabilityai/*`가 게이트되어 SD1.5로 대체했고, 1.5는 1.4의
     연속 학습이라 같은 계열이다. SD 계열 78.8→78.9%, 비SD 49.5→52.7%로
     사실상 변화 없음. **계열이 다른 인버터**(픽셀공간 ADM, GAN 인버전)로
     다시 해야 유효한 검증이 된다 — 게이트되지 않은 대안을 찾는 것이 선결 과제.
   - GAN 대 확산 2단 분기 — **부분 성공**. 3클래스 헤드만으로 biggan 역전이
     제거됐다(39.8→63.4%, AP 0.36→0.68). 역전이 클래스 구조였다는 뜻이므로,
     본격적인 2단 구조(1단 GAN/확산 판별 → 2단 계열별 탐지기)는 아직 남은
     후보다.
2. 2-2 타임스텝-프로파일(K=5) — 저비용, 하루면 결과.
3. 2-1 이중 브랜치 — 위 둘의 결과를 보고 설계 확정.
4. 강건성 표(2-4)와 AP 병기(2-5)는 어떤 방향이든 공통 적용.
